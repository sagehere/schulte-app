# 舒尔特方格专注力训练

一款在线的专注力训练工具，包含舒尔特方格、斯特鲁普、成语、古诗、记忆、译码六种训练模式。支持多用户、云端同步成绩、每日任务管理。

---

## 功能一览

- **6 种训练模式**：舒尔特方格（3×3 ~ 7×7，含倒序/色彩干扰）、斯特鲁普（文字/颜色）、成语填空、古诗填空、记忆翻牌、译码挑战
- **多用户系统**：每个用户有唯一识别码，登录后可同步成绩到云端
- **每日任务**：管理员可为用户分配每日训练任务，自动跟踪完成进度
- **成绩记录**：自动保存每次训练的成绩（用时、错误率等），保留近 90 天
- **公开成绩页**：每个用户拥有独立的公开页面 `/u/{识别码}`，可分享给他人
- **时区设置**：管理员可在管理面板中设置时区（默认东八区），所有时间显示以此为准
- **管理员面板**：点击顶部标题 5 次进入，可管理用户、重置密码、删除用户、设置时区

## 快速部署（Docker 推荐）

### 1. 准备环境变量

创建 `docker-compose.yml`（项目已自带），只需要设置两个必填变量：

| 变量 | 说明 | 示例 |
|------|------|------|
| `ADMIN_PASSWORD` | 管理员密码（必填） | `MyAdmin123` |
| `USER_CREATE_CODE` | 用户注册授权码（必填） | `Register2024` |

### 2. 启动

```bash
docker compose up -d
```

首次启动会自动创建 SQLite 数据库，无需手动初始化。

### 3. 访问

- **主页面**：`http://你的服务器IP:3000`
- **健康检查**：`http://你的服务器IP:3000/health`
- **用户公开页**：`http://你的服务器IP:3000/u/{识别码}`

### 停止

```bash
docker compose down
```

### 更新

```bash
docker compose pull
docker compose up -d
```

## 手动部署（无 Docker）

### 1. 安装 Node.js

需要 Node.js 18 或更高版本。

### 2. 下载项目并安装依赖

```bash
cd schulte-app
npm install
```

### 3. 配置环境变量

创建 `.env` 文件（与 `docker-compose.yml` 同目录）：

```bash
ADMIN_PASSWORD=你的管理员密码
USER_CREATE_CODE=用户注册授权码
```

### 4. 启动

```bash
npm start
```

默认监听 `0.0.0.0:3000`。

## 使用指南

### 首次使用

1. 打开主页面，点击右上角「用户中心」
2. 输入「授权码」（管理员设置的 `USER_CREATE_CODE`）
3. 设置「识别码」（字母+数字，唯一标识）和「密码」
4. 点击「创建用户」
5. 创建成功后，后续训练成绩会自动同步到云端

### 训练

点击主界面的训练按钮即可开始：

- **舒尔特**：按顺序点击 1~N 的数字方格
- **斯特鲁普**：判断文字颜色与文字含义是否一致
- **成语**：从打乱的汉字中拼出完整成语
- **古诗**：从打乱的诗句中拼出完整古诗
- **记忆**：记住方格内容，翻牌配对
- **译码**：根据符号对照表，翻译题目

### 管理面板

1. 点击页面顶部标题文字 **5 次**，弹出管理员登录窗口
2. 输入管理员密码（`ADMIN_PASSWORD`），进入管理界面
3. 可执行以下操作：

| 功能 | 说明 |
|------|------|
| 查询用户 | 查看用户资料和成绩数量 |
| 重置密码 | 当用户忘记密码时，管理员可强制重置 |
| 删除用户 | 永久删除用户及其所有数据 |
| 设置时区 | 修改时区（如 `Asia/Shanghai`、`America/New_York`），所有时间都按此显示 |

### 公开成绩页

每个用户都有一个独立的公开页面，地址为 `/u/{识别码}`。无需登录即可查看该用户的每日任务进度和历史成绩，页面显示的时间按管理员设置的时区转换。

## API 接口

所有接口的请求和响应均为 JSON 格式。

### 用户接口

| 方法 | 路径 | 说明 | 需要认证 |
|------|------|------|---------|
| POST | `/api/users` | 创建用户 | 授权码 |
| GET | `/api/users/:id` | 获取用户信息+今日任务 | 无 |
| PUT | `/api/users/:id` | 更新用户信息+保存任务 | 登录 |
| DELETE | `/api/users/:id` | 删除用户 | 登录+密码 |
| POST | `/api/users/:id/login` | 密码登录 | 无 |
| POST | `/api/users/:id/records` | 保存一条训练记录 | 登录 |
| GET | `/api/users/:id/public` | 获取公开信息+成绩 | 无 |

### 设置接口

| 方法 | 路径 | 说明 | 需要认证 |

## 数据存储

- **数据库**：SQLite，文件位于 `data/schulte.db`
- **数据表**：`users`（用户）、`tasks`（每日任务）、`records`（成绩记录）、`settings`（系统设置）
- **备份**：备份整个 `data/` 目录即可保存所有数据
- **自动清理**：成绩记录超过 90 天自动删除

---

## 数据安全

- 密码使用 PBKDF2 + SHA-256 加盐哈希存储
- 会话使用 SHA-256 哈希，不存明文 Token
- 管理员密码通过环境变量配置，不存储在数据库中
- 所有敏感字段（密码、Token）不会通过公开接口返回

---

## 技术栈

- **后端**：Node.js + Express
- **数据库**：SQL.js（SQLite WebAssembly 实现）
- **前端**：原生 JavaScript（无框架）
- **部署**：Docker / Docker Compose


## 理解训练（首轮）

首页新增「读懂一段话」「寻找原因」「读懂数学题」，也可访问 `/learning`。先在首页用户中心登录，然后选择单元。首批共 18 个单元，每模块 6 个，包含基础、连接两个层次。

每次练习分步作答；错误后给出方法提示，也可主动求助或查看讲解。统计分别显示首次独立答对、帮助后完成、看过讲解。回看原文不扣分。刷新或返回列表后，点击「继续上次练习」恢复服务器已保存的步骤。网络失败时重试原操作，服务器不会重复计数。

管理员周任务表支持三个新模块，目标次数按完成单元统计；完成不代表独立掌握。管理员可在导航配置中显示、隐藏或排序新入口，旧七项配置升级时自动补入三项。

「最近练习与技能记录」显示每步表现；「导出学习记录」下载带题库版本、首次答案、重试、提示和示范记录的 JSON。逐题信息仅本人或持有管理员凭据的 API 请求可读，公开成绩页只展示摘要。管理员 UI 查看逐题信息、CSV、90单元题库属于后续阶段。

首版列式题接受内容包列出的等价写法，支持全角字符、空格与 ×/÷ 规范化，不执行用户输入表达式。当前仅为训练记录，不提供标准化能力评分。内容需结合实际试用继续校订。

数据位于原数据库新增 `learning_sessions` 表，保留单元完整版本快照。学习详情随账号删除，改识别码时迁移。目前学习详情持续保留供导出，传统成绩摘要按90天清理，二者保留策略不同。备份前停止应用，再备份整个 `data/` 目录；上线前保留旧数据备份。

本地历史记录中无法确认所属用户的旧条目保留为访客记录，不自动归属任何登录账号。云端记录重新载入时附上当前用户标识。

### 可选浏览器验收

已有 Playwright 和 Chromium 的环境可运行 `node scripts/browser-smoke.cjs`。也可通过 `PLAYWRIGHT_MODULE`（Playwright 模块入口）和 `CHROMIUM_EXECUTABLE_PATH`（浏览器可执行文件）指定外部工具。脚本在39888端口启动临时数据库，验证三个模块、断点恢复、弱网重试、提示、导出、周任务、旧训练模式与账号切换，退出后清理临时数据。应用运行不需要安装浏览器。


## 教学闭环（第三阶段）

理解训练页面增加「学习练习 / 独立检查 / 到期复习」及层次、技能筛选。当前共有19个练习单元（原18个，加1个条件充分性补充练习）和18份独立检查材料。

- 独立检查：与练习使用不同材料；选项首次开始时随机排序并保存。每步只接收一次答案，可选择“这步暂时不会”；全部提交后统一展示答案和讲解。检查中不能使用提示或示范，刷新后继续原检查。每份检查材料每用户只可检查一次，之后可回看，不能重复取得新题证据。导出、历史记录和公开摘要在检查未完成时也隐藏正确性与讲解。
- 技能记录：按模块、技能、层次分别记录最近最多8份未见材料的首次独立表现。同材料的重复练习、同材料内同技能的多个步骤不会重复增加样本。历史会话缺少 phase/fresh 时按练习与最早接触该材料的会话兼容。
- 进阶建议：至少8份未见材料、2个不同日期、包含独立检查，整体及检查独立正确率均达到80%，才建议该技能尝试连接层次；连接层次有至少3个样本且低于80%时建议回到基础支持。其余数据不足显示“继续观察”。阈值在 `src/learning-progress.js:POLICY` 中，是应用内教学调度规则，不是标准化常模；用户仍可手动选择层次。小题库中部分技能尚不足8份材料，不会强行认定掌握。
- 到期复习：首次独立完成后约3天复习；需要帮助时次日复习。到期复习成功后按3、7天间隔安排，失败回到次日。同日重做不会清除已安排的复习，也不会增加跨日证据；间隔按管理员时区的日历日计算。优先同技能、适当层次的新练习材料；没有新材料时明确标为已见材料巩固。队列在访问页面时计算，无后台消息提醒。无到期项目时仍可自主选择材料复习，以完成家长安排的复习任务；提前复习不会推迟原定到期日。
- 周任务：管理员可指定方式（任意/学习练习/独立检查/复习）、层次和技能；首页任务跳转带入筛选。完成检查单元仅代表已提交，不代表掌握。旧任务没有筛选字段时仍按原模块次数计数。安排检查前注意剩余未见材料：检查库有限，用完后应扩充题库。

无新增应用依赖或数据库表；新会话沿用原 `learning_sessions` JSON，成绩摘要增加 `learningPhase/learningLevel/learningSkills`，逐题详情仍不公开。JSON 导出格式版本为2。

浏览器验收脚本 `scripts/browser-learning-cycle.cjs` 覆盖到期复习换材料、检查不提前讲解/断点恢复、以及按方式/层次/技能匹配的周任务。与首轮脚本使用相同 Playwright/Chromium 环境变量，在39889端口使用独立临时数据库。
