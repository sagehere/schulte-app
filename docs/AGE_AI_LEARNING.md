# 统一界面与适龄AI材料

## 使用方式

1. 在首页用户中心填写当前账号的真实生日并保存。年龄由服务器按管理员设置的时区和今天日期计算，不接受前端传入年龄。
2. 进入「读懂一段话 / 寻找原因 / 读懂数学题」，选择方式、层次和技能，点击「生成适合我的练习」。检查、复习方式也可生成新材料。
3. 生成并复核通过后才建立学习会话。刷新后可从最近记录继续；网络响应丢失时用原操作重试，已保存会话不会重复生成。
4. 原90单元与18份检查保留为「适龄备用」，按年龄限制层次。缺少生日不能开始新材料，既有会话仍可回看或继续。

AI不在打开页面时自动调用。当前每份材料包含3—5道选择题，服务端按已保存答案判分；开放口头表达仍通过家长观察记录，不由模型实时评分。每份新材料通常产生两次API请求：编写和复核。

## 年龄规则

| 年龄 | 生成材料长度参考 | 内容与数量关系 | 备用内容 |
| --- | --- | --- | --- |
| 6—8岁 | 40—120字 | 熟悉词汇、短句、具体情境、一层关系 | 7—8岁可用基础层；6岁仅AI |
| 9—10岁 | 100—260字 | 小学中年级词汇、两步关系、比较与单位 | 基础、连接 |
| 11—12岁 | 160—400字 | 小学高年级词汇、两三步关系、小数与条件 | 三个层次 |
| 13—15岁 | 220—550字 | 说明文、证据与假设、比例 | 使用AI生成 |
| 16岁及以上 | 250—700字 | 复杂句、反事实、多步信息筛选 | 使用AI生成 |

6岁以下提示家长陪同阅读，不提供此类独立AI训练。这些是产品内容约束，不是能力常模；年龄决定材料语言与数量范围，基础/连接/迁移决定思考方式，不能仅据年龄认定掌握。家长可以调整层次。

## Docker / Dockge配置

继续沿用现有镜像、数据卷、管理员密码和授权码。在当前堆栈的环境变量中**追加**以下配置，不要用示例整体覆盖原密码和挂载目录：

```yaml
environment:
  # 保留原有 NODE_ENV、PORT、ADMIN_PASSWORD、USER_CREATE_CODE、DB_PATH
  LEARNING_AI_BASE_URL: https://your-provider.example/v1
  LEARNING_AI_API_KEY: 在Dockge中填写你的API密钥
  LEARNING_AI_MODEL: 你的模型名称
  LEARNING_AI_MAX_TOKENS: "6000"
  LEARNING_AI_TOKEN_PARAMETER: max_tokens
  LEARNING_AI_DAILY_LIMIT: "20"
```

如果原Compose使用 `- KEY=value` 列表写法，请也使用列表追加，不混用两种YAML形式。仓库Compose已经提供相同变量的 `.env` 引用；使用该文件部署时，可在Dockge环境区或堆栈 `.env` 中填值。

基础地址通常以 `/v1` 结尾，程序调用 `/chat/completions`；也接受完整的Chat Completions地址。服务需支持JSON输出模式 `response_format: {type: "json_object"}`。部分模型要求 `max_completion_tokens`，可通过 `LEARNING_AI_TOKEN_PARAMETER` 切换。Token预算是每次调用上限，默认6000，可设3000—16000；推理模型的可见输出也受其内部推理消耗影响。默认每日每账号20份AI会话，可设1—100；失败请求另有限频。

填写后拉取最新镜像、重建应用容器，再刷新页面。三个必需项（地址、密钥、模型）未配齐时，AI按钮禁用，显示「尚未配置」，不会偷偷改用固定题来冒充生成。密钥仅从服务器环境读取，不进浏览器、学习导出或用户数据库；页面的「已配置」不代表已通过真实供应商连通性测试。

生成总超时90秒，反向代理的上游读取超时建议不低于120秒。中途网络失败可用原按钮重试；失败或复核不通过会明确提示，未形成有效材料时不创建练习。

## 质量、记录与费用控制

- 给服务商的编写请求只包含适龄段、模块、层次、技能和内容要求，不发送识别码、姓名、生日、历史原始答案或家长备注。复核请求包含新生成材料和适龄段。
- 先验证篇幅、步骤、技能、选项和唯一答案索引；数学至少有一个带算式的结果题，使用四则解析器核对算式、结果与选项，不执行模型提供的代码。
- 随后以单独请求复核题意、答案、提示和适龄性。模型复核仍会出错，并非人工审定或标准化试题；发现疑问使用原逐题反馈入口。
- 内容快照保存来源、适龄段、模型、版本、生成时间及指纹。相同段落即使换标题也保留相同材料ID，不能重复取得新题证据。独立检查拒绝已见材料，并继续保护未完成检查的答案。
- 每账号同一时刻只生成一份；同ID并发或保存后重试复用原结果。每分钟最多3次新的生成尝试；成功创建的AI会话按系统时区计入每日额度。限频在进程重启后重置，成功会话额度保存在原数据库中；失败API请求仍可能由供应商计费。
- AI和备用题库、不同AI适龄段在家长报告中分行统计，不混成一行比较。既有报告、复习与导出继续使用当次快照，不覆盖旧答案。

接口沿用原本人/管理员授权：`POST /api/learning/generate`，参数为稳定 `id`、`module`、`phase=train|check|review`、`level=1|2|3` 和可选 `focusSkill`。不接受用户提供的接口地址或密钥。

## 界面与验证

原首页内联样式原样提取为 `/assets/app.css`，首页、理解训练与家长页共同引用；学习页只补充布局规则，使用相同背景、字体、主题色、边框、圆角和按钮。

自动测试使用模拟兼容服务覆盖完整编写/复核链路、参数隐私、权限、年龄边界、算式错误、失败/超时、并发幂等、额度和检查遮蔽。浏览器核对使用独立的10岁用户样式夹具，非真实孩子记录；本轮没有真实供应商密钥，因此未做付费API联调，也未完成实体手机验证。
