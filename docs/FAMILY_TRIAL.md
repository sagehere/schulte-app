# 两周家庭试用

本轮目标是确认孩子能否使用、找出理解卡点和材料问题，并收集后续修订依据。这里提供试用流程；真实练习和观察由家庭完成，不预填结果。

## 开始前

1. 更新应用后，在首页登录孩子自己的账号，进入「理解练习 → 家长报告与观察」。
2. 展开「两周家庭试用安排」，选择起始日。日历保存在当前浏览器、按当前账号区分，仅供参考，不写入管理员周任务；换设备可手动选择同一天。
3. 每天约10分钟，网页练习最多两个单元。疲劳、烦躁或身体不舒服时缩短或暂停；漏做不额外补量。尽量保持设备、时段和帮助方式相近。
4. 默认从基础层次开始。已有练习经验时，可手动选适当层次，但同模块前后检查需保持层次一致；记录中途调整原因。

## 14天参考安排

| 天数 | 安排 | 记录重点 |
| --- | --- | --- |
| 1 | 段落理解：一份未见材料独立检查 | 是否能独立读明白，先不提示 |
| 2 | 数学读题：一份未见材料独立检查 | 条件、问题、比较关系 |
| 3 | 因果推理：一份未见材料独立检查 | 原因和结果，能否找依据 |
| 4 | 段落理解、数学读题各一个基础练习 | 卡住哪一步，使用何种提示 |
| 5 | 因果推理、段落理解各一个基础练习 | 提示是否读得懂 |
| 6 | 数学读题、因果推理各一个基础练习 | 首次理解与帮助后完成分开看 |
| 7 | 一小段新课文或一道新作业题 | 先独立说题意，再记录是否需要朗读或解释 |
| 8 | 复习段落理解、数学读题 | 优先到期技能；无到期项可自主选择 |
| 9 | 因果推理、段落理解各换一份材料 | 换句式后是否仍能理解 |
| 10 | 数学读题：另一份同层次新材料独立检查 | 使用新材料，避免边做边教 |
| 11 | 段落理解：另一份同层次新材料独立检查 | 环境、疲劳与帮助条件 |
| 12 | 因果推理：另一份同层次新材料独立检查 | 记录不会的步骤，不靠反复猜题 |
| 13 | 再选一道新纸面题或一小段文字 | 能否口头复述，是否仍需提示 |
| 14 | 家长复盘、筛选期间报告、导出数据包 | 找到下轮最值得调整的1—2个问题 |

独立检查中不提供示范或讲解，原文可以回看；不会时可先提交，结束后统一看讲解。请选择标注「新材料」的检查；检查数量不足时记录「材料不足」，不要把回看旧题当成新的能力证据。当前独立检查主要为基础层次，迁移层证据不足时继续观察。

## 发现材料或操作问题

在学习步骤下点击「这一步有疑问」，由家长在新页面填写反馈。完成后也可点击「反馈这份材料」。链接只带会话和步骤标识，不带密码或登录令牌；服务端核验当前账号拥有该会话，且步骤已经显示过。

家长页显示材料标题、版本及具体步骤，可选择「题意不清」「提示看不懂」「答案疑似有误」「操作困难」「练习太难」「练习太易」等标签。写明孩子怎样理解、当时看到了什么、是否给予帮助；可保留错误算式或原话，避免填写无关个人资料。意见与原始判分分开保存，不会直接改题或改分。

纸面观察可从日历第7、13天的按钮进入，也可直接新建。记录示例：

> 先自己读后说“求一共有多少”，漏掉“比昨天多”。我只重读了这半句，随后能指出比较的两天；没有告诉他算式。

## 复盘与导出

1. 在日历点击「查看试用期间报告」，自动选择起始日至第14天；尚未到第14天时截至今天。未来起始日不发起报告请求。
2. 选择全部模块或单个模块，点击「导出试用数据包」。若手动修改报告日期，导出以输入框中实际日期为准。
3. JSON包 `kind=family-trial, version=1` 包含日期/时区、私有报告、反馈关联材料版本、期间开始或完成的会话，以及期间观察关联的其他日期会话。会话为导出时快照，不是历史时点回放。
4. 已完成会话包含当次完整材料、随机选项顺序和原始答案，以便复核；未完成独立检查仅导出遮蔽视图，隐藏答案、正确性和讲解。原有全量学习JSON v3及三类CSV保持可用。
5. 数据包包含孩子的私人答案和家长备注。导出不会自动上传或通知任何人；家庭决定是否、向谁提供。

比较时先看同技能、同层次和同方式的记录，再结合纸面表现与实际帮助条件。只有前后少量检查不能判断训练效果；相同层次的不同材料也可能难度不同。报告在样本不足时显示「样本不足」。

## 收到真实反馈后的修订规则

- 先复现会话中的具体版本和步骤，核对题意、可接受答案、提示与讲解是否一致；操作问题先核对设备和复现步骤。
- 如题目确有错误或歧义，修订内容并增加版本号，补充对应内容/API回归校验。旧会话继续保留原快照，不静默覆盖历史答案。
- 纸面理解仍困难时，优先缩短材料、降低单次负担，围绕实际卡点调整下一轮练习。不要仅因网页完成次数增加而判为掌握。
- 本阶段交付试用工具与流程；题目修订和训练安排调整应依据之后产生的实际反馈，不能预先编造试用结论。

## 实现与验证

无新增依赖、表或后台任务。接口沿用 `/api/learning` 本人/管理员鉴权及 `no-store`：

- `GET /parents/feedback-context?sessionId=...&stepIndex=0`：步骤索引可省略，返回材料关联信息，不返回参考答案。
- `GET /parents/export?kind=bundle&from=YYYY-MM-DD&to=YYYY-MM-DD&module=reading`：日期范围最多366天，不晚于今天；模块可省略。

Node测试覆盖关联权限、可见步骤、版本、日期/模块筛选及部分/完整检查导出；`scripts/browser-parents.cjs` 覆盖反馈弹页、14天日历与跨月闰日、日期切换、账号独立起始日及文件下载。移动视口自动化不替代实体手机和家庭实测。
